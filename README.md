# 🩺 Pancreatic Cancer Detection using Machine Learning

A Machine Learning project that predicts the likelihood of pancreatic cancer using patient health data and clinical biomarkers. The project applies data preprocessing, classification algorithms, and performance evaluation techniques to assist in early disease detection.

---

## 🚀 Features

- Predicts pancreatic cancer risk using machine learning models.
- Performs data preprocessing and feature engineering.
- Handles missing values and data normalization.
- Compares multiple classification algorithms for improved performance.
- Provides an interactive prediction interface for user input.

---

## 🛠️ Tech Stack

- **Programming Language:** Python
- **Machine Learning:** Random Forest, CNN
- **Libraries:** Pandas, NumPy, Scikit-learn
- **Visualization:** Matplotlib, Seaborn

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/sharanya-1521/Pancreatic-Cancer-Detection-ML.git
```

Navigate to the project directory

```bash
cd Pancreatic-Cancer-Detection-ML
```

Install the required dependencies

```bash
pip install pandas numpy scikit-learn matplotlib seaborn
```

Run the application

```bash
python pancreatic_app.py
```

## 🔄 Workflow

1. Load the pancreatic cancer dataset.

3. Train machine learning models using the processed dataset.
